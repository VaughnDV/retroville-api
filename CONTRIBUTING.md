# Contributing

This repository is a personal engineering showcase. Outside contributions are
welcome as discussion, but there is no commitment to merge them.

1. Keep the repository private until `docs/security/secrets-audit.md` is signed off.
2. Install with `make install`.
3. Run `make lint typecheck test` before opening a pull request.
4. Do not add paid-API credentials to tests or fixtures.
5. Prefer characterisation tests when changing matching behaviour.
