# Contributor Covenant Code of Conduct

## Our pledge

We pledge to make participation in this project a harassment-free experience
for everyone.

## Our standards

Examples of behaviour that contributes to a positive environment include using
welcoming language, respecting differing viewpoints, and showing empathy.

Examples of unacceptable behaviour include harassment, trolling, and publishing
others' private information.

## Enforcement

Report issues to the maintainer listed in `docs/ownership.md`. The maintainer
will review and respond as appropriate for a personal showcase repository.

This code of conduct is adapted from the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
